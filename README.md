# ゆれ震度計 (yure-shindo)

スマホを机に置くと、ドアを閉めた・足踏みした・トラックが通った揺れを、**気象庁の計測震度の算出方法そのまま**で数値化する Web アプリ。

公開: https://yure-shindo.vercel.app (スマホで開く前提。PC ではデモ再生と気象庁 CSV の読み込みで試せます)

## 何をしているか

1. `DeviceMotionEvent.accelerationIncludingGravity`(m/s² → gal)を受信時刻つきでためる
2. 受信間隔は端末まかせでばらつくので、**時刻を見て 100Hz に線形補間で並べ直す**(`src/lib/resample.js`)
3. 直近 5.12 秒の窓で、告示どおりに計測震度を出す(`src/lib/intensity.js`)
   - 3成分をそれぞれ FFT(自前、`src/lib/fft.js`)
   - 周期効果 √(1/f) × ハイカット × ローカット を掛けて逆変換
   - ベクトル合成し、a0 以上の時間の合計がちょうど 0.3 秒になる a0 を探す
   - I = 2 log10(a0) + 0.94 。小数第3位で四捨五入してから第2位以下を切り捨て
4. 最初の 4 秒(置いて触らない)の値を**ノイズ床**とし、その 2 倍(計測震度で +0.6)未満は「測れない」と表示する

画面には、①3成分 → ②フィルタ → ③合成と 0.3 秒ルール → ④式と丸め、の計算過程を図で出す。サンプリング周波数・ばらつき・取りこぼし・端末で拾えない帯域・ノイズ床も数値で見せる。

## 気象庁の観測波形での検算

気象庁「[強震観測データ](https://www.data.jma.go.jp/eqev/data/kyoshin/jishin/index.html)」の気象庁観測点 15 か所(胆振東部 2018・熊本 2016・大阪府北部 2018・鳥取県中部 2016)で、公表された計測震度と照合している。

- 14 点で完全一致(厚真町鹿沼 6.5 = 震度7、熊本西区春日は生値 5.999 → 丸めで 6.0 など)
- 新千歳空港だけは 5.493 → 5.4(公表 5.5)。境界の 0.007 手前で、実際の震度計の実装差(検定基準 ±0.1)の範囲

**波形データは第三者提供が禁止されているため、このリポジトリには含めていない。** テストで使うには各自取得する:

```sh
pnpm fetch:jma   # tests/fixtures/jma/ に取得(.gitignore 済み)
pnpm test        # 取得していなければ、観測波形のテストだけスキップ
```

## 開発

```sh
pnpm install
pnpm dev     # http://localhost:5840
pnpm test
```

- ヘッドレス検証用に `window.__app`(`startDemo(scene, { speed })`、`loadCsvText(text)`、`state()` など)を公開
- `src/lib/synth.js` は「スマホを机に置いたときらしい」合成波形(ジッタ・取りこぼし・ノイズ・量子化つき)。振幅は目安

## 注意

スマホは地震計ではありません。机に置いただけなので机の揺れ方が混ざり、出るのは「その机の上の揺れ」です。地震の揺れの判断には使わないでください。
